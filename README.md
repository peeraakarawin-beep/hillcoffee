# ระบบบันทึกยอดขาย รายรับ และรายจ่าย 3 สาขา + รายจ่ายบริษัท
### (หนองคาย • โคราช • ขอนแก่น • รายจ่ายบริษัท)
**บันทึกแบบรายวัน สรุปยอดรายเดือน (Daily Entry & Monthly Summary Dashboard)**

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการยอดขาย รายรับจริง และรายจ่ายของธุรกิจที่มี 3 สาขา พร้อมระบบจัดสรรรายจ่ายส่วนกลางของบริษัท ใช้งานง่าย ทำงานได้แบบออฟไลน์ 100% ไม่ต้องติดตั้งโปรแกรมเสริมหรือฐานข้อมูลให้ยุ่งยาก

---

## 🌟 ฟังก์ชันระบบตามความต้องการครบถ้วน 100%

### 1. 💰 ระบบบันทึกยอดขาย (Sales Recording) 3 สาขา
รองรับ 3 สาขาหลัก: **หนองคาย**, **โคราช**, **ขอนแก่น**
บันทึกยอดขายรายวันแยกตาม **6 ช่องทาง** ได้แก่:
1. 💵 **ยอดขายเงินสด**
2. 📱 **ยอดขายเงินโอน**
3. 🛵 **ยอดขายแกรป (GrabFood)**
4. 🛵 **ยอดขายไลน์แมน (LINE MAN)**
5. 🛍️ **ยอดขายช็อปปี้ฟู้ด (ShopeeFood)**
6. 🇹🇭 **ยอดขายไทยช่วยไทย**
- ระบบคำนวณยอดขายรวมของวันนั้นให้อัตโนมัติทันที
- มีปุ่ม **"บันทึกยอดขายและสร้างรายรับด้วย ⚡"** ซิงค์ข้อมูลเข้าสู่ระบบรายรับให้อัตโนมัติในคลิกเดียว

---

### 2. 💵 ระบบบันทึกรายรับ (Revenue Recording) 3 สาขา
บันทึกรายรับจริงเข้าบัญชีและเงินสดประจำวันของ 3 สาขา (**หนองคาย**, **โคราช**, **ขอนแก่น**) แยกตาม **6 ช่องทาง**:
1. 💵 **เงินสด**
2. 📱 **เงินโอน**
3. 🛵 **แกรป**
4. 🛵 **ไลน์แมน**
5. 🛍️ **ช็อปปี้ฟู้ด**
6. 🇹🇭 **ไทยช่วยไทย**
- มีปุ่ม **"📥 ดึงยอดจากบันทึกยอดขายของวันนี้"** เพื่อดึงยอดตัวเลขมาปรับแก้ยอดหัก GP/ค่าธรรมเนียมได้สะดวกโดยไม่ต้องพิมพ์ซ้ำ

---

### 3. 📉 ระบบบันทึกและสรุปรายจ่าย (Expense Recording & Daily Expense Summary)
รองรับการบันทึกรายจ่ายทั้ง **3 สาขา** และ **รายจ่ายบริษัท (ส่วนกลาง/สำนักงานใหญ่)**:
- 📍 **สาขาหนองคาย**
- 📍 **สาขาโคราช**
- 📍 **สาขาขอนแก่น**
- 🏢 **รายจ่ายบริษัท** (ค่าใช้จ่ายสำนักงานใหญ่, ค่าเดินทางตรวจสาขา, ค่าการตลาดรวม, เงินเดือนทีมบริหาร)

จำแนกหมวดหมู่รายจ่ายตามที่กำหนด:
1. 🥤 **ต้นทุนวัตถุดิบเครื่องดื่ม** (เมล็ดกาแฟ, ชา, นม, ไซรัป ฯลฯ)
2. 🍲 **อาหาร** (เนื้อสัตว์, ผักสด, เครื่องปรุง ฯลฯ)
3. 🥐 **เบเกอรี่** (แป้ง, เนย, ครัวซองต์, ชีส ฯลฯ)
4. ⛽ **น้ำมันเชื้อเพลิงการเดินทาง** (ค่าน้ำมันส่งของ, ค่าเดินทางตรวจสาขา)
5. 👥 **ค่าแรง** (เงินเดือนพนักงานประจำสาขา, ค่าจ้างรายวัน, โอที)
6. 🏢 **ค่าเช่าสาธารณูปโภค** (ค่าเช่าพื้นที่, ค่าน้ำ, ค่าไฟฟ้า, อินเทอร์เน็ต)
7. 📦 **ค่าใช้จ่ายอื่นๆ / เบ็ดเตล็ด**

### 3.1 📅 ระบบสรุปรายจ่ายประจำวัน และส่งออกเป็นรูปภาพ (Daily Expense Summary & Image Export)
มีแผงสรุปรายจ่ายรายวันในแท็บ **"บันทึกรายจ่าย"** สามารถใช้งานได้ทันที:
- 📆 **เลือกวันที่ต้องการสรุป**: ตรวจสอบรายจ่ายย้อนหลังหรือของวันนี้ได้ทันที
- 🔘 **ตัวเลือกดูรายจ่ายรวมหรือแยกแต่ละสาขา**:
  - 🌐 **สรุปรายจ่ายรวมประจำวัน (ทุกสาขา + บริษัท)**: สรุปยอดค่าใช้จ่ายทั้งหมดของวันนั้นในภาพรวม
  - 🟣 **สาขาหนองคาย**: ดูเฉพาะรายจ่ายของสาขาหนองคาย
  - 🟠 **สาขาโคราช**: ดูเฉพาะรายจ่ายของสาขาโคราช
  - 🟢 **สาขาขอนแก่น**: ดูเฉพาะรายจ่ายของสาขาขอนแก่น
  - 🔵 **รายจ่ายบริษัท**: ดูเฉพาะรายจ่ายส่วนกลาง/สำนักงานใหญ่
- 📊 **การแสดงผลสถิติรายจ่ายประจำวัน**:
  - 3 บัตรรวม: ยอดรายจ่ายรวมของวัน, จำนวนรายการที่จ่าย, ยอดเฉลี่ยต่อรายการ
  - การ์ดสรุปยอดแยก 3 สาขา + บริษัท พร้อมเปอร์เซ็นต์สัดส่วน
  - แถบสัดส่วนรายจ่ายแยก 6 หมวดหมู่ พร้อมยอดเงินและเปอร์เซ็นต์
  - ตารางแจกแจงรายการรายจ่ายประจำวัน (เวลา, สาขา, หมวดหมู่, รายการ, หมายเหตุ, ยอดเงิน)
- 🖼️ **ปุ่มส่งออกรูปภาพสรุปรายจ่าย (JPG) ใน 1 คลิก**:
  - สร้างภาพ Infographic ความกว้าง 1080px สวยงาม คมชัด ออกแบบสำหรับส่งสรุปรายจ่ายโดยเฉพาะ
  - มีช่องลงนาม/ผู้ตรวจจ่าย (Sign-off & Verification)
  - ดาวน์โหลดเป็นไฟล์ JPG หรือ **กดคัดลอกรูปภาพเพื่อวาง (Ctrl+V) ใน LINE ได้ทันที**
- ✉️ **ปุ่มส่งสรุปรายจ่ายประจำวันทาง Gmail**: จัดข้อความพร้อมส่งอีเมลรายงานผู้บริหารทันที

### 4. 📊 แดชบอร์ดสรุปยอดรายเดือน (Monthly Summary & Analytics)
- **ตัวเลือกเดือน/ปี**: เลือกดูข้อมูลย้อนหลังหรือเดือนปัจจุบันได้ทันที (พร้อมปุ่มเดือนก่อนหน้า/ถัดไป)
- **ตัวกรองสาขา**: เลือกดูภาพรวมทุกสาขาพร้อมกัน หรือเจาะจงเฉพาะสาขา (หนองคาย / โคราช / ขอนแก่น / รายจ่ายบริษัท)
- **4 บัตรสรุป KPI หลัก**:
  1. 💰 **ยอดขายรวมประจำเดือน** (Total Sales)
  2. 💵 **รายรับรวมประจำเดือน** (Total Revenue)
  3. 📉 **รายจ่ายรวมประจำเดือน** (Total Expenses)
  4. 📈 **กำไรสุทธิประจำเดือน** (Net Profit = รายรับรวม - รายจ่ายรวม) พร้อมคำนวณ Profit Margin %
- **การ์ดเปรียบเทียบผลประกอบการ 3 สาขา + บริษัท**: สรุปยอดขาย, รายรับ, รายจ่าย และผลกำไร-ขาดทุนแยกเป็นรายสาขา
- **แผนภูมิกราฟเปรียบเทียบสัดส่วน (Interactive Charts)**:
  - สัดส่วนยอดขาย 6 ช่องทาง (Progress Bar)
  - สัดส่วนรายจ่าย 6 หมวดหมู่ (Progress Bar)
  - กราฟแท่งเปรียบเทียบยอดขาย vs รายรับ vs รายจ่าย แยก 3 สาขา
- **ตารางสรุปรายวันตลอดทั้งเดือน (Day-by-Day Table)**: แสดงตัวเลขยอดขาย, รายรับ, รายจ่าย, กำไรสุทธิของแต่ละวัน (1 ถึง 31)

### 5. ✉️ การส่งสรุปรายการทาง Gmail ได้ทันที (Instant Gmail Dispatch)
- 🚀 **เปิด Gmail พร้อมส่งทันทีใน 1 คลิก**:
  - กดปุ่ม **"ส่งสรุปทาง Gmail"** ที่แถบเมนูด้านบน หรือในหน้ารายงาน
  - ระบบจะสร้างข้อความสรุปผู้บริหารที่จัดรูปแบบไว้อย่างเป็นระเบียบ เรียบร้อย สวยงาม
  - เลือกได้ทั้ง **สรุปภาพรวมประจำเดือน** หรือ **สรุปยอดประจำวัน** (ระบุวันที่ได้)
  - เลือกว่าจะสรุป **ทุกสาขารวมกัน** หรือ **เจาะจงรายสาขา** ได้
  - กรอกอีเมลผู้รับ (เช่น `boss@gmail.com, account@gmail.com`) ระบบจะจดจำอีเมลล่าสุดไว้ให้อัตโนมัติ ไม่ต้องพิมพ์ซ้ำ
  - เมื่อกดปุ่ม **"เปิด Gmail และส่งทันที 🚀"** หน้าต่างเขียนจดหมายของ Gmail จะเปิดขึ้นมาใหม่พร้อมกรอก ถึง (To), หัวข้อ (Subject) และเนื้อหาสรุปครบถ้วน สามารถกดส่งได้ทันที!
- 📋 **ปุ่มคัดลอกข้อความสรุป (Copy to Clipboard)**: สำหรับนำข้อความสรุปไปส่งต่อในกลุ่ม LINE, Telegram, หรือแชทอื่นๆ ได้ทันที
- 📧 **เปิดด้วยโปรแกรมอีเมลในเครื่อง (mailto:)**: รองรับการส่งผ่าน Outlook, Thunderbird, หรือ Windows Mail

### 6. 🖼️ การส่งออกยอดสรุปเป็นรูปภาพ JPG (Instant Image Infographic)
- 💾 **ดาวน์โหลดรูปภาพสรุปยอดความละเอียดสูง (JPG)**:
  - กดปุ่ม **"ส่งออกรูป JPG"** ที่แถบเมนูด้านบน หรือปุ่ม **"ส่งออกรูปสรุปรายจ่าย JPG"** ในหน้าบันทึกรายจ่าย
  - ระบบจะสร้างรูปภาพ Infographic ความละเอียดคมชัดสูง (1080px) ด้วย HTML5 Canvas สวยงาม โมเดิร์น
  - เลือกประเภทรายงานได้:
    1. **สรุปภาพรวมประจำเดือน** (ยอดขาย + รายรับ + รายจ่าย + กำไรสุทธิ)
    2. **สรุปยอดรวมประจำวัน** (ยอดขาย + รายรับ + รายจ่าย + กำไรสุทธิของวันนั้น)
    3. **สรุปรายจ่ายประจำวัน (เฉพาะรายจ่าย)**: แจกแจง 6 หมวดหมู่รายจ่าย + รายการจ่ายทั้งหมดของวัน + ช่องตรวจจ่าย
    4. **สรุปรายจ่ายประจำเดือน (เฉพาะรายจ่าย)**: สรุปยอดรายจ่ายสะสมทั้งเดือน
  - เลือกว่าจะสรุป **ทุกสาขารวมกัน** หรือ **เฉพาะเจาะจงสาขา** (หนองคาย / โคราช / ขอนแก่น / รายจ่ายบริษัท)
  - กดปุ่ม **"ดาวน์โหลดรูปภาพ JPG 🖼️"** บันทึกเป็นไฟล์ภาพลงเครื่องทันที
- 📋 **คัดลอกรูปภาพลงคลิปบอร์ดในคลิกเดียว (Copy Image)**:
  - กดปุ่ม **"คัดลอกรูปภาพ (Ctrl+V ใน LINE ได้ทันที)"** แล้วเปิดห้องแชท LINE หรือ Facebook กด `Ctrl+V` ส่งภาพให้ทีมงานหรือผู้บริหารได้ทันที สะดวกรวดเร็วที่สุด!

### 7. 📑 การออกรายงานและการส่งออกข้อมูล (Reports & Export)
- 🖨️ **พิมพ์รายงานสรุปประจำเดือน (A4 / PDF)**: จัดรูปแบบหน้ากระดาษมาตรฐานสวยงาม พร้อมตาราง Matrix แยกตามสาขา
- 📊 **ส่งออก Excel (CSV)**: รองรับภาษาไทย 100% (UTF-8 with BOM) เปิดใน Microsoft Excel ตัวอักษรไม่เพี้ยน:
  - ส่งออกรายงานงบการเงินรายเดือนฉบับเต็ม
  - ส่งออกยอดขายประจำเดือน
  - ส่งออกรายรับประจำเดือน
  - ส่งออกรายจ่ายประจำเดือน
  - ส่งออกสถิติรายวันประจำเดือน
- 💾 **สำรองและกู้คืนข้อมูล (Backup JSON)**: สามารถ Export ไฟล์ข้อมูลทั้งหมดเก็บไว้ หรือย้ายไปเปิดใช้งานบนคอมพิวเตอร์เครื่องอื่นได้ทันที
- ✨ **ปุ่มโหลดข้อมูลตัวอย่างจำลอง (Demo Data)**: ทดลองดูระบบและกราฟตัวอย่างได้ใน 1 คลิก

## 🚀 วิธีการเปิดใช้งาน

1. ดับเบิ้ลคลิกที่ไฟล์ **`เปิดโปรแกรม.bat`** หรือ **`start_app.bat`** (หรือดับเบิ้ลคลิกไฟล์ `index.html`)
2. ระบบจะเปิดขึ้นบนเว็บเบราว์เซอร์ของคุณทันที (Google Chrome, Microsoft Edge ฯลฯ)
3. ใช้งานได้ทันที **ไม่ต้องต่ออินเทอร์เน็ต** ข้อมูลจะถูกจัดเก็บบนเครื่องอย่างปลอดภัย
